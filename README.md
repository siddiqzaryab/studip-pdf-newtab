<h1 align="center">StudIP PDF NewTab</h1>

<p align="center">Opens Stud.IP PDFs in a normal browser tab instead of the popup.</p>

## What it does

Click a PDF link in Stud.IP and it opens in a new tab next to the current one, so you get your browser's full PDF viewer. Ctrl/Cmd-clicks, download links and all non-Stud.IP sites are left alone. Everything runs locally, with no tracking.

## Install

Works in Chrome, Edge, Brave and Arc.

1. Download or clone this repo
2. Open `chrome://extensions` and turn on **Developer mode**
3. Click **Load unpacked** and select this folder
4. Reload Stud.IP

## Troubleshooting

- **PDF downloads instead of opening:** your Stud.IP forces downloads, which the extension can't change.
- **Popup still appears:** [open an issue](../../issues) with the HTML of the PDF link (right-click it, **Inspect**).
